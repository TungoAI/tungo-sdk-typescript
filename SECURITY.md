# Security policy

## Supported versions

Security fixes are released for the latest minor version of the Tungo SDK for TypeScript. Upgrade to the newest release before reporting a problem.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: https://github.com/TungoAI/tungo-sdk-typescript/security/advisories/new

Include the SDK version, the runtime version, and the smallest example that shows the problem. Never include a real API key or webhook secret in a report; if a key was exposed, revoke it in the Tungo console first.

You will get an acknowledgement within five working days. We will agree on a disclosure date with you and credit you in the release notes unless you prefer otherwise.

## Scope

This policy covers the code in this repository. Problems in the Tungo API itself should be reported the same way; they will be routed to the platform team.
